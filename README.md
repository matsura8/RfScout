# RfScout

Native Windows app (csharp), built with the DevFlow workflow.

```powershell
dev build        # debug build
dev run          # build + launch
dev test         # unit tests + smoke test
dev lint         # format check + static analysis
dev audit        # security audit
dev beta         # signed beta kit + Windows Sandbox config
```

See `C:\workspace\devflow\docs\WORKFLOW.md` for the full process.
